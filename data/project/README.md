# Реальные данные объекта

Этот каталог предназначен только для подтверждённых данных текущего объекта.
Демонстрационные числа из `data/sample` не копировать: используйте их только как
образец структуры колонок. Пороги, WLL, DAF и правила должны иметь источник в ППР,
паспорте оборудования или нормативе и быть подтверждены ответственным инженером.

## Необходимые входы расширенного пилота

- `works.xlsx` или `works.csv` — работы, бригады, техника и интервалы;
- `zones.csv` — рабочие зоны, проходы, края и координаты в метрах;
- `lifts.csv` — грузы, массы, парусность, стропы, вылеты и оттяжки;
- `wind.csv` — измеренные средние скорости и порывы с высотой измерения;
- `crews.csv` — бригады и численность;
- `crane.yaml` — геометрия и пределы крана;
- `crane_load_chart.csv` — паспортная грузовая характеристика;
- `rules.yaml` — правила со ссылками на конкретные пункты ППР/норм;
- исходный IFC здания — путь передаётся отдельно команде импорта.

Для быстрого контура дополнительно нужен `building.json` с активным ярусом и
графом проходов. Не заполняйте его предположениями: координаты подтверждает ПТО.

## Порядок запуска

```bash
cd /Users/asan_97kglist.ru/risk-sim
.venv/bin/risk-sim import-ifc "/путь/к/модели.ifc" --data data/project
.venv/bin/risk-sim pilot --data data/project --output results/project --swing-engine mujoco
```

До запуска ответственный инженер задаёт допустимое расхождение для сверки с
ручным расчётом. Результат симуляции — поддержка решений, а не расчёт по нормам.
