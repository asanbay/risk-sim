Не удалось открыть 3D-сцену

Эта страница показывает results/pilot/building.glb и читает results/pilot/scene_bundle.json. Three.js и зависимости хранятся локально, интернет не нужен.

# 1. собрать сцену и короткую анимацию: FRAMES=24 EVERY=40 FPS=12 ./blender/render.sh # 2. экспортировать GLB из анимированной сцены: blender -b results/pilot/building.blend -P blender/export_gltf.py -- --out results/pilot/building.glb # 3. открыть страницу через локальный сервер (не file://!): python -m http.server 8766 # затем: http://localhost:8766/viewer/pilot_three.html

Без Blender остаётся автономный вьюер: results/pilot/viewer.html — он работает офлайн и без единой зависимости.
